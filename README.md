# FitLog

## It's a simple project built with Next.js.



## About

FitLog is a workout tracking application built with Next.js and TypeScript. It helps users explore exercises and organize their workout plans.


## Features

- Browse workout exercises.
- View detailed exercise information.
- Add exercises to Today's Plan.
- Save exercises for later.
- Track workout duration and calories.
- Responsive design for mobile and desktop.


## Technologies Used

- Next.js
- TypeScript
- React
- Tailwind CSS
- DaisyUI
